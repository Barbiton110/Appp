# InstaPost – שיווק אוטומטי לאינסטגרם לעסקים

אפליקציית SaaS שבה כל עסק נרשם, מחבר את חשבון האינסטגרם שלו, מעלה תמונות (או יוצר אותן ב-AI), כותב כיתוב (או נותן ל-AI לכתוב) – ובוחר מתי לפרסם. השרת מפרסם אוטומטית בזמן שנבחר.

## מה יש בפנים

- **הרשמה והתחברות** – כל עסק רואה רק את החשבונות והפוסטים שלו.
- **חיבור אינסטגרם** דרך Business Login for Instagram (OAuth רשמי של Meta). אפשר לחבר כמה חשבונות.
- **העלאת תמונות** – עד 10 בבת אחת. התמונות מומרות אוטומטית ל-JPEG ונחתכות ליחס שאינסטגרם מקבל (4:5 עד 1.91:1).
- **יצירה ב-AI** – כיתובים עם Claude, תמונות עם OpenAI. מבוסס על "פרטי העסק" שבהגדרות.
- **תזמון בשתי דרכים**
  - *תאריך ושעה* – בוחרים מועד מדויק. כמה תמונות = אחת ביום, החל מהמועד שנבחר.
  - *תור יומי* – כל תמונה נכנסת ליום הפנוי הבא בשעה היומית הקבועה של העסק.
- **לוח תזמונים** – מתוזמנים / פורסמו / נכשלו, עם שינוי זמן, עריכת כיתוב, פרסום מיידי ומחיקה.
- **מתזמן ברקע** – בודק כל דקה, עד 3 ניסיונות חוזרים, ומרענן טוקנים לפני שהם פגים (כל 60 יום).
- **אבטחה** – טוקנים מוצפנים במסד (AES-256-GCM), סיסמאות ב-bcrypt, הגבלת ניסיונות התחברות.

## הרצה מקומית (5 דקות, בלי אינסטגרם אמיתי)

דרוש Node.js 20 ומעלה.

```bash
npm install
cp .env.example .env      # ב-Windows: copy .env.example .env
npm start
```

פתחו http://localhost:3000, הירשמו, ובהגדרות לחצו **"הוסף חשבון דמו"**. במצב `IG_DRY_RUN=1` הכול עובד מקצה לקצה, רק שהפרסום עצמו מדומה.

## חיבור לאינסטגרם אמיתי

1. **חשבון מקצועי** – באפליקציית אינסטגרם: הגדרות ← סוג חשבון ← מעבר לחשבון מקצועי (Business או Creator).
2. **אפליקציית Meta** – ב-[developers.facebook.com](https://developers.facebook.com/apps) צרו אפליקציה מסוג Business, והוסיפו את המוצר **Instagram** ← *API setup with Instagram business login*.
3. **הרשאות** – `instagram_business_basic` ו-`instagram_business_content_publish`.
4. **Redirect URI** – הוסיפו: `https://YOUR-DOMAIN/auth/instagram/callback`
5. **.env** – מלאו `IG_APP_ID`, `IG_APP_SECRET`, `PUBLIC_BASE_URL=https://YOUR-DOMAIN`, ושנו ל-`IG_DRY_RUN=0`.
6. **שרת ציבורי** – אינסטגרם מוריד את התמונה מהשרת שלכם, ולכן הכתובת חייבת להיות ציבורית ב-HTTPS. לבדיקה מקומית: `ngrok http 3000` (או cloudflared) והכתובת שמתקבלת היא ה-`PUBLIC_BASE_URL`.

> **חשוב לגבי SaaS:** במצב פיתוח, רק חשבונות שהוספתם כ-testers באפליקציה יכולים להתחבר. כדי שכל עסק יוכל להתחבר, צריך לעבור **App Review** של Meta על הרשאת הפרסום (כולל סרטון הדגמה ומדיניות פרטיות) ו-Business Verification.

## AI (אופציונלי)

| יכולת | משתנה | הערה |
|---|---|---|
| כיתובים | `ANTHROPIC_API_KEY` | מפתח מ-console.anthropic.com |
| תמונות | `OPENAI_API_KEY` | ניתן להחליף מודל ב-`OPENAI_IMAGE_MODEL` |

בלי מפתחות – הכפתורים פשוט מושבתים, ושאר האפליקציה עובדת.

## העלאה לאוויר (פרודקשן)

האפליקציה צריכה **שרת שרץ כל הזמן** (בגלל המתזמן) ו**דיסק קבוע** (למסד ולתמונות). מתאים: Railway, Render, Fly.io, או VPS (DigitalOcean / Hetzner) עם `pm2`.
לא מתאים כמו שהיא: Vercel / Netlify (serverless – אין תהליך רקע ואין דיסק קבוע).

צ'קליסט:
- `ENCRYPTION_KEY` אקראי וארוך (אם משנים אותו – החשבונות המחוברים יצטרכו להתחבר מחדש).
- `PUBLIC_BASE_URL` עם https.
- גיבוי לתיקיית `data/`.
- הריצו **מופע אחד** של השרת (שני מופעים = שני מתזמנים).

## מבנה הקוד

```
src/
  server.js      הפעלת השרת
  db.js          מסד SQLite וטבלאות
  auth.js        הרשמה, התחברות, סשנים
  instagram.js   OAuth, טוקנים ופרסום ל-Instagram API
  scheduler.js   מתזמן: פרסום פוסטים, ניסיונות חוזרים, רענון טוקנים, תור יומי
  media.js       העלאה ועיבוד תמונות
  ai.js          כיתובים ותמונות ב-AI
  routes.js      ה-API
public/          ממשק המשתמש (עברית, RTL, מותאם לנייד)
```

## מגבלות ידועות והמשך

- כרגע תמונה בודדת לפוסט. קרוסלות, Reels וסטוריז נתמכים ב-API ואפשר להוסיף.
- לאינסטגרם יש מכסת פרסומים יומית לכל חשבון; אפשר לבדוק אותה ב-`/{ig-user-id}/content_publishing_limit`.
- רעיונות להמשך: תשלומים ומנויים (Stripe), תוכן אוטומטי מלא (AI מייצר שבוע של פוסטים בלחיצה), אנליטיקות, פייסבוק/טיקטוק.
